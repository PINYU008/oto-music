音日 v1.4
首次開啟會自動升級 IndexedDB 至版本 2：保留原音訊，另建 meta 索引；請勿清除網站資料。舊版程式無法開啟新版資料庫，請勿降版。日常只讀歌曲資訊及當前、下一首音訊。
備份：展開音樂庫備份與還原 → 製作備份 → 點選下載，確認 ZIP 已存至檔案 App 或外接儲存。ZIP 未加密、未壓縮，上限小於 4 GiB，包含原始音樂、播放清單及最愛。還原僅支援 Oto 原始 ZIP；先驗證 CRC32，再加入新副本，不覆寫既有音樂，重複還原會產生副本。大型備份可能受裝置空間及瀏覽器限制。單首匯出可從歌曲選單操作。
不需伺服器，不上傳音樂。iOS 背景播放仍受系統限制。首次更新請連網，關閉所有舊版分頁與主畫面捷徑後重新開啟。尚未在實體 iPhone/iPad 驗證資料庫升級及下載還原。
